## Digits

Digits is a website where users register and login to create and save contacts. With each contact, you can save their name, address, and phone number. Within each contact, you may also create and save timestamped notes.

## Overview
The first page is the homescreen where users can see the purpose and the vision behind the website. The second page link is where users can add contacts. Each contact can contain a first name, last name, address, image, and description. The third page link is where users can see the list of contacts that they have saved. They can see the contact info and have the opportunity to add timetstamped notes and edit their contacts.

The last navbar link is where users can either sign in, sign up, sign out, or change passwords for their accounts to login.
